# Pendahuluan Praktikum Pertemuan 2

## Tugas Mandiri

Tugas mandiri praktikum ini dikerjakan secara individu sebagai persiapan sebelum pelaksanaan tugas kelompok.

Pada tugas ini terdapat beberapa materi yang dipelajari, yaitu:

1. Pemetaan routing dan kontrak URL.
2. HTTP method dan HTTP status code.
3. Perbandingan paradigma REST, GraphQL, gRPC, dan WebSocket/polling.
4. Penggunaan HTTP client dan DevTools.
5. Perbandingan SQL mentah dengan ORM.

Seluruh tugas dikerjakan menggunakan dokumentasi, pengujian, dan bukti screenshot sesuai dengan ketentuan praktikum.
